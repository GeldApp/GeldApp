# GeldApp GitHub Pages site

This is a standalone, buildless marketing site. It is not part of the React/Tauri desktop bundle.

Preview locally with `python3 -m http.server 4178 --directory site` and open `http://localhost:4178`. The GitHub Pages artifact is the contents of this directory, served at `https://geldapp.github.io/GeldApp/`; asset URLs are relative so the `/GeldApp/` project path works.

The product preview is illustrative and uses synthetic figures. Keep readiness and roadmap claims aligned with the product README, TODO, architecture, and verification notes. No downloadable release is advertised until a release exists.
