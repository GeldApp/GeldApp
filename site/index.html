MACOS PREVIEW

Try GeldApp with Homebrew

After the first guarded release is published and its cask update has merged, install the universal preview with these commands.

The preview is ad-hoc signed and unnotarized, without an Apple Developer ID signature. macOS may ask you to approve the first launch. Uninstalling removes the app and preserves your local vault. Use sample data only.

Check published releases
Installbrew install --cask geldapp/tap/geldapp
Upgradebrew upgrade --cask geldapp
Uninstallbrew uninstall --cask geldapp

HONEST ABOUT THE BUILD
